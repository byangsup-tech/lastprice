- **KB금융 / otrCprInvstmntSttus**: 관측된 최초 `000` = **2015**
- **KB금융 / irdsSttus**: 관측된 최초 `000` = **2015**

> 문서상 표기는 "2015년 이후 부터 정보제공" 이다. 위 값은 *관측된* 최초 `000` 이며, 해당 연도에 그 법인이 그 항목을 공시하지 않았을 수도 있으므로 "데이터가 YYYY년부터 제공된다" 로 단정하지 않는다.

## ③ 주석 조회 API 의 보험계약부채·CSM 커버리지

**사전 조사 결론: DART OpenAPI 에 주석(註釋) 조회 엔드포인트는 존재하지 않는다.** XBRL 주석은 API 가 아니라 웹 일괄다운로드(TSV)로만 제공되고(`opendart.fss.or.kr/disclosureinfo/fnltt/xbrlnote/main.do`), `fnlttXbrl.xml` 에는 본표만 들어 있다. 아래는 동양생명보험 2024년으로 이를 실측 확인한 것이다.

- `fnlttSinglAcntAll` **CFS**: status=000, 220행
  - `재보험계약` 매칭 4건: BS|재보험계약부채, BS|재보험계약자산, CIS|재보험계약자산(부채)순금융손익, SCE|재보험계약자산(부채)순금융손익
  - `보험계약부채` 매칭 2건: BS|보험계약부채, BS|재보험계약부채
  - `투자계약부채` 매칭 1건: BS|투자계약부채
- `fnlttSinglAcntAll` **OFS**: status=000, 201행
  - `재보험계약` 매칭 4건: BS|재보험계약부채, BS|재보험계약자산, CIS|재보험계약자산(부채)순금융손익, SCE|재보험계약자산(부채)순금융손익
  - `보험계약부채` 매칭 2건: BS|보험계약부채, BS|재보험계약부채
  - `투자계약부채` 매칭 1건: BS|투자계약부채
- `fnlttXbrl.xml`: status=000 (115338 bytes)
- 사업보고서 원문(`document.xml`): status=000, 3987911자, 인코딩 utf-8
- 원문 전문 키워드 출현 횟수: `보험계약부채`=108, `계약서비스마진`=0, `CSM`=0, `재보험계약`=277, `투자계약부채`=39

**결론**

- 보험계약부채(재무상태표 집계 계정)는 정형 API 로 확인됨
- CSM(계약서비스마진)은 정형 API 에서 확인되지 않음(예상대로) → **Phase 2 원문 파싱이 필요하다**
