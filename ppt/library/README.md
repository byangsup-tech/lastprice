# library/ — 승인 사례 보관소

**조직 승인이 확정된 덱**의 동결 사본. `decks/`가 작업장이라면 여기는 기록실이다 —
다음 덱을 만들 때 "이 방에서 통과된 실물"을 근거로 쓰고, 부서 이동 시 새 팩 추출의 벤치마크가 된다.

## 규약

- 승인 확정 시 `library/<YYYYMM>-<안건>/`에 다음을 **복사**한다 (이동 아님 — decks/ 원본 유지 여부는 자유):
  - `deck-spec.json` (승인 시점 그대로 동결)
  - 최종 `.pptx`
  - `data/` (있으면 — 스펙 재현에 필요)
  - `NOTE.md` (선택 — 방에서 나온 반문·수정 지시 등 구멍 검사에 쓸 실전 프라이어)
- `INDEX.md`에 한 줄 추가 (아래 표)
- 동결본은 수정하지 않는다. 재사용할 때는 decks/로 복사해 새 덱으로 작업

## 폼 스터디 승률과의 관계

덱보드의 `formstudy:runs`는 "**내가** 고른 폼"의 기록이고, 이 INDEX는 "**조직이** 승인한 결과"의 기록이다 —
층위가 다르므로 자동 연동하지 않는다. 승인 과정에서 폼이 수정됐다면 INDEX 비고에 남긴다
(예: "bars → compare_rows로 교체 지시받음") — 이 기록이 쌓이면 조직 팩의 폼 선호로 승격할 근거가 된다.
